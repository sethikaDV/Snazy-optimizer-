# 🆕 What's New

## 🎯 1. Pro Sensitivity for Device

Get device-based sensitivity recommendations for your favorite games. 🎮🔥

### 🎮 Supported Games

- 🔥 Free Fire
- 🔥 Free Fire MAX
- 🎯 PUBG Mobile
- 🎯 BGMI
- 🎮 Call of Duty: Mobile

### ⚙️ How It Works

1. 🎮 Select your game.
2. ✅ Tap **"Yes, continue"**.
3. 📱 Enter your phone model.

Example:

`Redmi Note 12 8GB`

4. 🧠 SNAZY analyzes the entered device information offline.
5. 💻 A hacker-style terminal animation displays the optimization process.
6. 📊 Recommended sensitivity values are generated.

### 📋 Generated Values

Depending on the selected game, SNAZY can provide:

- 🎯 Free Fire scope sensitivity
- 📷 PUBG camera sensitivity
- 🎯 PUBG ADS sensitivity
- 📷 COD Mobile camera sensitivity
- 🎯 COD Mobile ADS sensitivity
- 💡 Additional gameplay tips

📋 A **Copy to Clipboard** button is also included.

### 🧠 How Values Are Calculated

The recommendations are generated offline using information derived from the entered phone name, including:

- ⚡ Estimated performance tier
- 📱 Screen size
- 🧠 RAM

⚠️ These values are **recommended starting points**, not measured or officially tested values.

🎯 Players should test the settings in training mode and fine-tune them according to their device and playstyle.

# ⚡ 2. Per-Game Refresh Rate & DPI Lock

V3.2.21 introduces a new per-game display optimization system. 📱🎮

The previous FPS Counter feature has been replaced by this system. 📊➡️⚡

### 📱 Per-Game Profiles

Configure display settings separately for each game.

### ⚡ Refresh Rate

Select a refresh rate supported by your device's display panel.

SNAZY attempts to apply the selected refresh rate when **Boost** is activated. 🚀

📱 Refresh-rate control depends on your phone manufacturer and Android version.

After Boost, SNAZY reports whether the requested refresh rate was successfully accepted. ✅

### 🎚️ Render Resolution

Choose a render resolution from:

- 🟢 90%
- 🟢 80%
- 🟡 70%
- 🟠 60%
- 🔴 50%

### 🔧 Automatic DPI Scaling

DPI is scaled together with the selected resolution to help maintain a consistent UI size. 📐📱

---

# 🚀 Boost & Restore

When you press **Boost**:

1. 💾 SNAZY captures the current display configuration.
2. ⚙️ Your selected game profile is loaded.
3. ⚡ The selected refresh rate is applied.
4. 🎚️ The selected resolution is applied.
5. 🎮 Your game is ready to launch.

When you press **Restore**:

- 🔄 The original display configuration is restored.

### 🛠️ Reset Display

If something doesn't look right, use:

**🔄 Reset display to normal now**

This allows you to return the display settings to normal immediately.

⚠️ Lowering the resolution changes the **entire Android display**, including SNAZY itself, until the settings are restored.
