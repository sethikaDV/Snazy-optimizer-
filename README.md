## What's New in V4.5.7

**V4.5.7 is a maintenance update focused on fixing visual bugs and improving the app interface.**

### 🐛 Bug Fixes & Improvements

- **Game Color Fade Fix** — Fixed an issue affecting game colors and fade effects.
- **Notch & Display Fix** — Fixed an issue where the device notch could overlap or cover app content.
- **UI Improvements** — Improved the visual experience across supported devices.
- **Stability Improvements** — Minor fixes for a smoother, more consistent experience.
